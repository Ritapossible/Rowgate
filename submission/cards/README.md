# Rendered frames for the video

Made by `scripts/render_cards.py` at 1920×1080 in the site's palette. Re-run it if a number
changes.

| File | Where it goes |
| --- | --- |
| `numbers-card.png` | 2:31–2:42, the comparison |
| `end-card.png` | the last three seconds, after the red check |
| `caption-*.png` | transparent overlays, drop one on each shot where that cell appears |

The captions are 900×170 with transparency. Place them bottom-left with about 60px of margin,
fade in over 4 frames, hold while the cell is on screen.
